# Instructions — Deploy & Manage MultiModalRag

---

## Local Setup

```bash
# 1. Clone the GitHub repo
git clone https://github.com/irajkooh/AgenticMultimodalRag
cd AgenticMultimodalRag

# 2. Install Python dependencies
pip install -r requirements.txt

# 3. Install Ollama (if not already installed)
curl -fsSL https://ollama.com/install.sh | sh

# 4. Pull the LLM model
ollama pull llama3.2

# 5. (Ollama starts automatically when app.py runs)

# 6. Run the app
python app.py
# → Frontend: http://localhost:7860
# → Backend:  http://localhost:8000/docs  (FastAPI Swagger)
```

## HuggingFace Space Setup (already done)

Space: https://huggingface.co/spaces/irajkoohi/AgenticMultimodalRag

### Space environment variables

Go to: Space → Settings → Variables and secrets

**Secrets** (encrypted):

| Secret name           | Value                        |
|-----------------------|------------------------------|
| `GROQ_API_KEY`        | Groq API key                 |
| `AgenticMultiModalRag_Token` | HuggingFace write token      |

Get Groq key: https://console.groq.com  
Get HF token: https://huggingface.co/settings/tokens (write scope)

**Variables** (plain text):

| Variable name           | Value                               |
|-------------------------|-------------------------------------|
| `MultiModalRag_dataset` | `irajkoohi/AgenticMultiModalRag_dataset`   |

> Without `MultiModalRag_dataset`, all indexed documents are wiped on every cold start.
> With it, data is saved to the HF Dataset and restored on startup automatically.

## Deploy a change

```bash
./deploy_changes.sh "describe your change"
```

Stages modified tracked files, commits, pushes to GitHub, and force-pushes to HF Space.

To add new untracked files first:
```bash
git add <new-file>
./deploy_changes.sh "describe your change"
```

## Adding source documents (PDFs, DOCX, etc.)

**Via UI:** Upload tab → drop file → indexing starts automatically.

**Via git** (bakes into Docker image — available on fresh Space deploy):
```bash
cp new_doc.pdf data/
git add data/new_doc.pdf
./deploy_changes.sh "add document"
```

**Upload to HF Dataset directly** (available immediately on running Space):
```bash
python3 -c "
from huggingface_hub import HfApi
import os, sys
api = HfApi(token=os.environ['AgenticMultiModalRag_Token'])
api.upload_file(
    path_or_fileobj=sys.argv[1],
    path_in_repo='data/' + os.path.basename(sys.argv[1]),
    repo_id='irajkoohi/MultiModalRag_dataset',
    repo_type='dataset',
)
" data/yourfile.pdf
```

## Useful API endpoints

| Endpoint              | Method | What it does                               |
|-----------------------|--------|--------------------------------------------|
| `/status`             | GET    | App health + ChromaDB chunk count          |
| `/system/info`        | GET    | Env · Device · LLM (powers status bar)     |
| `/ask`                | POST   | Ask a question (RAG + memory, streaming)   |
| `/upload`             | POST   | Upload and index a file                    |
| `/upload_url`         | POST   | Index a URL (2-level deep crawl)           |
| `/documents`          | GET    | List indexed documents                     |
| `/documents/{name}`   | DELETE | Delete a single indexed document           |
| `/documents`          | DELETE | Delete all indexed documents               |
| `/reextract`          | POST   | Re-extract tables and images from all docs |
| `/session/reset`      | POST   | Clear conversation memory                  |

## Reset corrupted vectorstore

```bash
./deploy_changes.sh "fix: reset db" --reset-db
```

Clears all vectorstore files from the HF Hub dataset. Space starts fresh on next cold start.

---

## Rollback

```bash
git log --oneline
git revert <commit-hash>
./deploy_changes.sh "revert: <reason>"
```

## What is NOT committed

| Excluded              | Reason                                               |
|-----------------------|------------------------------------------------------|
| `vectorstore/`        | Restored from HF Hub on cold start                   |
| `data/images/`        | Generated by re-extract; restored from HF Hub        |
| `data/tables/`        | Generated by re-extract; restored from HF Hub        |
| `_secrets/`           | Tokens and personal notes — never commit             |
| `.venv/`              | Local Python environment                             |
